# 模板包

一个包项目的骨架：一个 `.ecfg`（包本体）、一份说明、一个 `art/` 目录。

    cp -r packs/template packs/my_pack
    mv packs/my_pack/template.ecfg packs/my_pack/my_pack.ecfg
    # 改 pack::id，去掉条目的注释，开始写

## 写的时候记住三件事

1. **名字是接口**：存档只存数字 id，名字到 id 的映射随存档走。改名字等于换了一个东西；
   在文件中间插入一条，会让它后面同类内容的 id 全部 +1——引擎按名字重新定位已放置的格子，
   所以这不会毁掉你的地图，但 id 会变。
2. **同名内容报冲突，不合并**：本体内容先注册，你的包只能在它后面追加；重名会被报告并保留先注册的那个。
3. **字段是你的**：引擎只读"名字"，不读字段——**唯一的例外是 `image`**（见下）。
   字段可以随便改形状，不影响存档。

## 贴图：多边形**风格**的图片

已确认的美术方向是"多边形风格"，**但仍然是图片资源**：低多边形、平色块、硬边的贴图，
引擎按普通 PNG 加载（Ore 自带解码器），不做矢量多边形渲染。

    structure::
        wall::
            image:"art/wall.png"      # 相对本包目录；引擎加载时校验它存在
            solid:true

* 图片放 `art/`（或任何你喜欢的子目录），用相对路径引用；
* 文件不存在、或不是能解码的图片，加载报告里会有一条错误（不会静默画成空白）；
* 尺寸、切片方式（一格一张？图集？）、描边/渐变、动画帧这些**美术规则还没定**，
  见 `docs/GAME_DESIGN.md` §7 第 13 项——你给了规则我就照着做。

引擎侧的现状：包加载时会解析并校验 `image` 字段；把它画到屏幕上属于 M2 的世界渲染。

## 关于"没有玩家角色"

游戏没有角色，所有玩家都是上帝视角：输入驱动相机（平移/缩放）与指针（指向格子、框选、下达动作）。
所以包里**不会有**玩家贴图、角色数据或出生点这类条目——需要的是地图、结构、机器、配方与需求。
