# 图片放这里

贴图是**多边形风格的图片**（低多边形、平色块、硬边），引擎按普通图片资源加载——PNG，
`ore::Image::load_png` 已经能解码（非隔行、8 位、灰度/RGB/调色板/灰度+透明/RGBA）。

约定（`docs/MODS.md` §0）：

* 位置：包目录下的 `art/`（或任何你喜欢的子目录），文件名小写加下划线（官方内容用蛇形命名）；
* 引用：内容条目里写 `image:"art/xxx.png"`，路径相对**声明它的那个文件**（内容文件在 `content/` 里时写
  `../art/xxx.png`）；
* 引擎会校验文件存在、且是 PNG，不然就在加载报告里记一条错误（不会静默画成空白）；
* **一块内容一张图**（不切片、不进大图集）、**尺寸随意**（一格通常 128 或 256 像素，不缩放也不拒绝）；
  引擎只把整张图铺上去，所以描边、渐变、半透明与动画帧都由你在图片里画——这些**还没有约定**，连同
  配色表、一个结构跨格怎么办、每个瓦片层用哪些图，都等设计者给规则（`docs/GAME_DESIGN.md` §7 第 13 项）。

现在这个目录里只有这份说明：模板包加载后注册 0 项内容、也不引用任何图片。
