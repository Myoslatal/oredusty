# 图片放这里

贴图是**多边形风格的图片**（低多边形、平色块、硬边），引擎按普通图片资源加载——PNG，
`ore::Image::load_png` 已经能解码（非隔行、8 位、灰度/RGB/调色板/灰度+透明/RGBA）。

约定（提案，等你确认，见 `docs/GAME_DESIGN.md` §7 第 13 项）：

* 位置：包目录下的 `art/`，文件名小写加下划线；
* 引用：内容条目里写 `image:"art/xxx.png"`，路径相对**本包目录**；
* 引擎会校验文件存在，不存在就在加载报告里记一条错误（不会静默画成空白）；
* 图片尺寸、一格一张还是一张图集、是否描边/渐变/半透明、动画帧——都还没定，等你给规则。

现在这个目录是空的：模板包加载后注册 0 项内容、也不引用任何图片。
